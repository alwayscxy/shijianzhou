# 南京邮电大学实践周任务：文本词频统计与检索系统
## 一、项目背景
文本词频统计与检索系统的应用场景覆盖学术研究、商业分析、政务舆情监测、日常信息管理等多个重要领域，是兼具实用性与技术综合性的开发项目。
在学术研究中，系统可助力研究人员高效分析文献关键词的分布规律与发展趋势；在商业分析中，企业能通过其挖掘用户反馈、市场报告中的高频词汇，为商业决策制定提供数据支撑；在政务舆情监测方面，系统可实时捕捉公众讨论热点，提升政策响应效率与舆论引导能力；在日常信息管理中，用户能够借助系统对文档、邮件、笔记等内容进行快速归类与检索，大幅提升信息处理的效率与准确性。

## 二、系统基本开发要求
1.  数据导入与基础存储统计：支持从文本文件导入数据，采用链表或数组结构存储单词信息，实现单词的去重处理与词频的精准统计。
2.  单词检索功能：提供单词检索入口，输入目标单词后可快速返回其出现次数及首次出现位置，需对检索算法进行优化，提升检索效率。
3.  词频排序与结果导出：支持按词频进行降序/升序排序，实现冒泡排序、快速排序等多种排序算法的开发与应用，保证排序结果准确且性能优良；同时支持将排序后的词频统计结果导出为文本文件。
4.  散列表存储与冲突处理对比：引入散列表结构存储所有单词，设计分布均匀、合理性高的散列函数；实现拉链法与线性探测法两种冲突处理方式，并对比二者的性能差异（含冲突率、平均检索效率），为实际应用提供数据参考。
5.  结果可视化与批量导出：对词频统计结果进行可视化展示，如生成柱状图直观呈现词汇分布情况；支持将高频词汇批量导出为文件，提升数据的可复用性与团队协作效率。
6.  交互界面设计：设计并实现简洁、易用的交互界面，实现词频统计、排序、散列存储、结果可视化等核心功能的演示，确保用户操作便捷，系统结果反馈清晰、及时。
7.  功能拓展基础要求：在完成上述核心功能的基础上，可根据个人开发能力进行功能扩充，为系统增加更多实用特性。

## 三、推荐功能扩充方向
基于基础开发要求，建议从**中文分词能力拓展**方向进行功能升级，进一步增强系统的实用性和场景适应性，具体拓展要求如下：
1.  实现中文分词功能：基于词典或简单规则完成中文词语的切分，同时实现中文词语的词频统计，兼容中英文词频统计的双重需求。
2.  多条件筛选与排序：支持按词语长度、拼音首字母等多种条件对统计结果进行筛选与排序，丰富系统的数据处理维度。
3.  个性化检索与筛选：可拓展自定义筛选规则，如支持按词频阈值筛选高频/低频词汇，提升系统的灵活度。
